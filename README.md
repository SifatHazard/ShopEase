# ShopEase — Multi-Role E-Commerce Web Application

A full-featured e-commerce website built with **HTML, CSS, JavaScript, PHP, and MySQL**

## Roles & Features

| Role               | Feature 1                                                                  | Feature 2                                                                          |
| ------------------ | -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| **Admin**          | Manage Products & Categories (activate/deactivate, delete, add categories) | Manage Orders & Users (assign delivery agents, cancel orders, block/unblock users) |
| **Seller**         | Add & Manage Own Products (add, edit, delete, image upload, stock)         | View & Update Orders for Their Products (mark items shipped/delivered)             |
| **Customer**       | Browse/Search Products + Cart (search, filter by category, add to cart)    | Checkout & Order Tracking (place order, view status, see delivery OTP)             |
| **Delivery Agent** | Accept / Reject Assigned Orders                                            | Update Delivery Status with OTP Proof of Delivery (or report failed delivery)      |
